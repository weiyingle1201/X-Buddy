# 演示视频脚本（约 150 秒）

> 录屏建议：桌面浏览器 1440×900，打开 <https://weiyingle1201.github.io/X-Buddy/>。全程直接操作产品，不使用 PPT。

| 时间 | 画面操作 | 旁白要点 |
|---|---|---|
| 0:00–0:12 | 首页空状态，指向顶部“演示数据（构造）”徽标 | “X-Buddy 是投资研究者的 Agent 工作台。无需 Key 即可体验；数据为结构对齐扶摇 API 的构造样例，填 Key 即切换实时数据。” |
| 0:12–0:40 | 点「研究贵州茅台的基本面和估值」，计划卡片逐项变绿 | “先解析标的，再两阶段展开 8 个取数任务；每个任务显示数据源、耗时、重试、缓存。” |
| 0:40–1:00 | 报告出现：结论分级 → 点 `E-0xx` → 右侧证据面板定位 | “每个数字都能回到原始接口、字段、口径、时点；计算值给出公式和上游证据。结论分为事实、推断、不确定；资讯缺失，所以不做归因。” |
| 1:00–1:10 | 批准“写入长期记忆”，切到「记忆」面板 | “写入长期状态要我确认；持仓这样的敏感信息需要授权才能读取。” |
| 1:10–1:30 | 点「比较宁德时代和比亚迪」，指向 ⚠ 与“数据冲突” | “Agent 交叉校验了指标接口和利润表，发现比亚迪净利润同比不一致，冲突值不参与排序。” |
| 1:30–1:50 | 「工具/故障演练」把估值设为“服务错误”，再研究五粮液；指向“降级”与“静态PE(降级)” | “接口失败会重试、走降级链，并显式标注口径变化，而不是静默给出正常结论。” |
| 1:50–2:10 | 研究中点「停止」→「从检查点继续」；「观测」面板展示时间线与 P50/P95 | “每步写检查点，可停止、恢复、回滚；所有调用都有 trace、时延和成本统计。” |
| 2:10–2:30 | 输入「茅台明天会涨吗？现在能买吗？」 | “预测和买卖诉求会被改写为基于证据的研究任务，报告里不会出现预测或建议。” |
